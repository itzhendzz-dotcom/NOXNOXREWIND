# Install NOXXA REWIND v3

Copy into:

`Android_unprotected/data/com.rockstargames.gtasa/mods/`

Layout:
```
mods/
├── libNoxxaRewind.so
└── NoxxaRewind/
    └── rewind_user.wav
```

Remove older `libNoxxaRewind.so` before replacing it. Keep only one NOXXA REWIND native library installed.

V3 defaults to a 13-second history and a compact top-left control. Hold the button to rewind. Release to commit the selected past. Double tap performs a short quick rewind.
