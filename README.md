# NOXNOXREWIND

## Current: NOXXA REWIND v2 — ANCHOR MODE

**The player stays. The world rewinds.**

The original v0.1 prototype proved that native time-history playback could compile and run on GTA SA Android. v2 is a clean architecture shift based on in-game testing: the player is now a fixed time anchor with a one-hand gesture, while nearby vehicles and pedestrians rewind around them.

Source: [`v2/`](v2/)

GitHub Actions builds an installable `NOXXA_REWIND-v2.0.0` artifact for GTA SA Android 2.00 / armeabi-v7a / AML.

The rewind audio is original and generated from source by `v2/scripts/synth_audio.py`; no proprietary Life is Strange audio is included.

Legacy v0.1 files are kept temporarily as a reference while v2 stabilizes.
